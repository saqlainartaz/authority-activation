# Connected visual evidence

The screenshots in `screenshots/` are generated by
`frontend/e2e/connected-application.spec.ts` against the isolated compatible
backend and disposable synthetic data. They cover the retained admin workflows,
an honest unsupported-onboarding error, persisted source processing, and the
connected workspace in desktop light and phone dark layouts.

The `admin-redesign-*` screenshots use intercepted synthetic responses and the
production Next.js build. They document the revised operator shell at desktop,
tablet, and phone widths without backend writes or provider calls.

These images demonstrate local rendering with real application-shaped backend
responses and deterministic provider substitutes. They are not evidence of a
deployed environment or live-provider execution.
